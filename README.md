# 集体仪式司仪和礼宾交接

仪式统筹使用家庭留言、用名登记和不同岗位的已收卡记录。
演练资料使用虚构单位、人员与业务文字。资料以 UTF-8 JSON 给出，各文件按收到的顺序保存，正文中引述的名字和词形按原样保留。

## 资料格式

每份资料是记录数组。编号的作用范围是所在资料集，同一业务对象如有不同版本则另列记录。空字符串表示交接文件未填写，空数组表示未列条目。没填写的值无法代替明确的反面事实。

- `data/people.json` 保存id、家庭、登记名、台上可用名、读音、读音范围。登记名为后台核身份使用。读音范围表示该注记的可见岗位。

- `data/programme.json` 保存id、家庭、时间、环节、地点、接收岗。环节由现场统筹登记，动作不能越过现有舞台通行约定。

- `data/requests.json` 保存id、时间、家庭、发件、范围、内容。发件是身份核实结果，范围是该留言获准使用的最宽范围。

- `data/run_of_show.json` 保存id、环节、岗位、创建、时态、正文。各岗位交接时间与动作。原始台本和已分发话术均按收到时的内容留存。

- `data/desk_notes.json` 保存id、环节、文字。岗位既有约定和家庭已允许的回退说法。

## 阅读与运行

使用 Python 3.11.2 和标准库，无需安装第三方包。在仓库根目录可列出交接资料，或查看一条原始记录的所有版本。测试核查文本能原样读取和资料之间的关联。

```text
python3 -m corpus
python3 -m corpus requests --id M6
python3 -m unittest discover -s tests -v
```
